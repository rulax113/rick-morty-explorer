# Marvel Library

Aplikacja SPA w Angular do przeglądania i zarządzania bohaterami Marvel.

## Użytkownik
Fan komiksów i filmów Marvel, który chce przeglądać postacie i śledzić ich statusy.

## Problem
Brak wygodnego narzędzia do filtrowania i przeglądania bohaterów z dodatkowymi informacjami.

## Główne encje
- **Character** – name, description, series, status, power, tags

## Planowane operacje CRUD
- Create – dodawanie nowej postaci
- Read – lista postaci i widok szczegółów
- Update – edycja danych postaci
- Delete – usuwanie postaci

## Technologie
- Angular
- TypeScript
- SCSS
- Angular Router
